# Fallen Gateways — Les Portes Déchues — English overview

A Nether exploration datapack featuring the ruins of Nerath, lore books, aqueducts, ruined colonies and giant gateways.

**Official CurseForge page:** https://www.curseforge.com/minecraft/data-packs/fallen-gateways-the-nether-before-the-fall-les

**Files/versions:** ZIP French_Edition_Audited / English_Edition_Audited.

Install Fabric mods in a matching mods/ setup, datapacks in the world's datapacks/ folder, Bukkit plugins in a compatible server plugins/ folder, and modpacks using a compatible launcher. Back up your worlds and verify compatibility before updating.
