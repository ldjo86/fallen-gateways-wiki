# Installer Fallen Gateways — Les Portes Déchues

**Version(s) repérée(s) :** ZIP French_Edition_Audited / English_Edition_Audited.

1. Télécharge le ZIP compatible depuis CurseForge.
2. Place-le dans le dossier datapacks/ de ton monde.
3. Exécute /reload ou redémarre le serveur.
4. Confirme sa présence avec /datapack list.
5. Teste ses effets sur une copie du monde.

## Avant d'installer

Une livraison locale Les Portes Déchues V13.0.0 FR/EN a été inspectée en lecture seule. Elle diffère des noms des archives publiques CurseForge, donc ne pas confondre les éditions.

Vérifie la page CurseForge : https://www.curseforge.com/minecraft/data-packs/fallen-gateways-the-nether-before-the-fall-les.
