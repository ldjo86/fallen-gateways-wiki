# Fallen Gateways — Les Portes Déchues — Guide pratique

Nerath était autrefois un monde habitable. Explore aujourd'hui ses vestiges dans le Nether, entre colonies en ruines, passerelles et ouvrages gigantesques.

> Version concernée : V13.0.0 (livraison locale étudiée). Les renseignements non vérifiés dans le jeu sont signalés.

## 1. Préparer l'exploration du Nether

Installe le datapack compatible dans le monde, conserve une copie de ta sauvegarde puis explore des secteurs nouveaux du Nether. Évite de supposer que les lieux déjà générés recevront toutes les nouvelles structures.

## 2. Comprendre les ruines de Nerath

Les constructions racontent un passé disparu : colonies, aqueducs, voies d'évacuation et fortifications. Chaque découverte contribue à l'ambiance du datapack, sans nécessiter une nouvelle dimension annoncée.

## 3. Chercher les livres et les récompenses

Explore les structures, conserve les livres de lore et examine les récompenses liées aux lieux. Les taux d'apparition des structures ou des butins ne sont pas inventés : l'atlas sépare les fichiers présents des résultats prouvés en jeu.

## 4. Choisir la bonne édition

Des éditions en français et en anglais existent sur CurseForge. L'archive locale V13 étudiée possède un nom différent de certaines distributions publiques : vérifie toujours celle que tu installes.

## Conseils pour démarrer

1. Télécharge le **ZIP correspondant à ta version Minecraft** depuis CurseForge.
2. Dépose-le dans le dossier `datapacks/` de ton monde.
3. Recharge avec `/reload` ou redémarre le serveur, puis contrôle l'installation avec `/datapack list`.
4. Fais tes essais sur une sauvegarde de test avant de modifier ton monde principal.

**À faire en jeu :** explorer de nouveaux territoires, documenter les ruines trouvées et collectionner les histoires de Nerath.

## Fiabilité

Une archive locale V13.0.0 FR/EN pour les familles 1.21 à 26.3 a été inspectée. Cette livraison ne doit pas être confondue avec les ZIP publics de noms différents.

Le JAR/ZIP local contient des fonctions et des tables de butin documentées dans l'atlas technique ; les rencontres et structures sont décrites sans images de créatures.
