# Fallen Gateways — Les Portes Déchues — Questions fréquentes

## Quelle version installer ?

ZIP French_Edition_Audited / English_Edition_Audited. Choisis celle qui correspond à ta version Minecraft ; lis la page CurseForge.

## Le guide a-t-il vérifié toutes les mécaniques ?

Non. Une livraison locale Les Portes Déchues V13.0.0 FR/EN a été inspectée en lecture seule. Elle diffère des noms des archives publiques CurseForge, donc ne pas confondre les éditions.

## Comment obtenir de l'aide ?

Lorsque le dépôt sera créé sur GitHub, signale la version du fichier, celle du jeu, ton chargeur et les étapes qui reproduisent le problème.
